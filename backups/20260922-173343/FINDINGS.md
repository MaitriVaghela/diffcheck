## The silent divergences

### `new_account_hold`

Disagreements per model: `gpt-4o-mini` 88, `gpt-4o` 88, `gpt-4.1-mini` 88.

Passed 5/5 golden tests. Legacy returned `True`, the table returned `False`.

```json
{
 "amount": 811.17,
 "item_count": 10,
 "country": "US",
 "tier": "basic",
 "account_age_days": null,
 "coupon": null,
 "category": "electronics",
 "weight_kg": 20.83,
 "is_return": false
}
```

Missing fields: `account_age_days`, `coupon`. The legacy rule coalesces a missing value with `or 0`, so an absent value is read as zero -- a real decision hidden in an idiom. The decision table has no coercion, the ordered comparison does not hold, the row is skipped, and the table returns the opposite answer.

## Reading these numbers

- `clean` means no divergence appeared in the sampled inputs, not that the two implementations are equivalent.
- A crashed spec disagrees everywhere without ever executing; read the logic counts for translation quality.
- Some rules may be inexpressible in the target format. Check whether a violation had any valid alternative before counting it against a model.
- Rules, tests, thresholds, inputs and prompt are frozen across models, so differences between columns are attributable to the model.
